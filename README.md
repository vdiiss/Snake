# Snake

Домашнее задание 1 «Змейка на C++»: консольная игра для терминала Linux
(среда — VS Code + WSL).

## Часть I. Базовая программа — `base/snake.cpp`

Змейка ползает по полю, ест еду, растёт и проигрывает при столкновении
со стеной или собственным хвостом.

- поле 10 × 10, змейка `@` стартует в центре, её длина 1;
- еда `*` появляется в случайной свободной клетке;
- съела еду — длина +1, счёт +1;
- стена `#` или свой хвост `o` — проигрыш, в конце выводится счёт;
- змейка заняла всё поле — победа;
- одно нажатие клавиши направления — один ход, развернуться на 180° нельзя.

## Часть II. Вариант 6 «Сад» — `variant_06/garden.cpp`

В саду растут фрукты трёх типов:

| Фрукт      | Очки | Особенность                                              |
|------------|------|----------------------------------------------------------|
| `A` яблоко | +1   | обычный фрукт                                            |
| `B` банан  | +2   | обычный фрукт, встречается реже яблока (35 %)            |
| `C` вишня  | +3   | вырастает не дальше 3 клеток от головы и исчезает через 3 хода, если её не съесть |

- на поле всегда лежат 2 обычных фрукта (яблоки или бананы); на место съеденного сразу вырастает новый;
- вишня появляется время от времени (20 % на каждом ходу, пока её нет); сколько ходов ей осталось, видно под полем;
- любой фрукт удлиняет змейку на 1;
- цель — собрать урожай: набрать 30 очков; стена или хвост — проигрыш;
- в конце выводится счёт и статистика: сколько съедено фруктов каждого типа и сколько вишен упущено.

## Управление

| Клавиша          | Действие                         |
|------------------|----------------------------------|
| `W` / `↑`        | вверх                            |
| `S` / `↓`        | вниз                             |
| `A` / `←`        | влево                            |
| `D` / `→`        | вправо                           |
| `H`              | справка: цель, правила, клавиши  |
| `Q`              | выход                            |

В русской раскладке работают те же клавиши: `Ц Ф Ы В`, `Р`, `Й`.
Перед началом игры справка выводится автоматически.

## Сборка и запуск (WSL)

```bash
cmake -S . -B build
cmake --build build -j
./build/snake         # часть I
./build/variant_06    # часть II, вариант 6 «Сад»
cd build && ctest --output-on-failure
```

Без CMake:

```bash
g++ -std=c++17 -Wall -Wextra -o snake base/snake.cpp
g++ -std=c++17 -Wall -Wextra -o garden variant_06/garden.cpp
```

Параметр `--seed N` фиксирует генератор случайных чисел: партия с теми же
нажатиями повторяется один в один (так устроены тесты).

## Тесты

CTest запускает игру с заранее записанными нажатиями клавиш и проверяет итог:
вывод правил, удар о стену, вызов справки во время игры, столкновение с хвостом,
а для «Сада» — полную партию до победы со статистикой по фруктам.
